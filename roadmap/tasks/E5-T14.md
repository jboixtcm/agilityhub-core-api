## Steps
1. **E5-T09 review #3: re-anchor bookings.** `DemoBookingSeeder` books only into the weeks the re-anchor generated (`fresh` offsets from `DemoPlanningSeeder`, filtered on `row.week()`), never into kept weeks. Test.
2. **E5-T09 #4: weekly re-anchor.**
   - A kept, still-`GENERATED`, non-past week whose `planning.weeks` row has `validate: true` is validated. The current week of a weekly re-anchor then has bookable classes.
   - Add the one-week case to `T_06_28_reanchor…`.
3. **E5-T09 #7.** `COUNTER_WRITERS` names the S08 writer classes only, or `counters` becomes package-private behind an S08-owned port. Method references (`::counters`) must be caught too.
4. **E5-T09 #10.** `DemoSeedActor.as` refuses to run outside the `local`/`test` profiles, as `DemoPlanningService` does. Test.
5. **E5-T09 Question 4.** `activities.domain.ActivityExternalEvent` no longer implements `DomainEvent`, as the `*ForeignEvent`s since E5-T09. `CONSUMER_ENVELOPES` covers it.
6. **E5-T11 review #2.**
   - The public methods of `SystemNotificationService` (`appOnce`, `smsIntentOnce`, `pushIntentOnce`) return to `Propagation.NEVER`.
   - The N-15 consumer uses a `MANDATORY` variant, so a business transaction can never join these methods by mistake.
   - List the other callers in the report.
7. **E5-T11 #3.** `offerNotifiedAt` is set only when at least one N-15 row was queued: send first, mark after, in the same transaction. The Javadoc and the model row say «the N-15 rows of this offer were written». Test the no-recipient case.
8. **E5-T11 #8: FIFO expiry.** An offer that expired (`confirmBy` passed, back to `ACTIVE`) never gets «La plaça ja s'ha ocupat» from a later seat-taken event. Clear `offerNotifiedAt` on expiry, or compare with the expiry. Test.
9. **E5-T11 #5: tests.** For every keyed public route, a `SUSPENDED` club reached with a wrong key or with no key answers `403 INVALID_API_KEY`, never `CLUB_SUSPENDED`.
10. **E5-T11 #6 and #7.**
    - The Javadoc of `PublicClubAccess` states the tiny timing difference; slugs are public anyway.
    - The plans route declares `@SecurityRequirement(name = "clubApiKey")`, like the pages route.
    - Regenerate the snapshot.
