# E11-T18 · The template club's catalogs

## Objective
S17 R-17-13 and T-17-14 say the template club `club-template-default` carries catalogs and message templates in ca/es/en, and D19's «Catàlegs base» step clones the parts the platform admin ticks (`POST /platform/clubs/{id}/catalog-clone {fromClubId, parts: [LEVELS, RINGS, PLANS, FAQ, MESSAGE_TEMPLATES]}`, R-17-08). Today the seed has `levels: []`, `rings: []`, `plans: []`, `faq: []`, `messageTemplates: []`, so a new club clones nothing. Jordi (21-10, ruling E153): the usual case is a club that starts from a generic set and then adapts it, so the starter set must be there and easy to add — part by part, editable afterwards. No change to the clone API or the wizard: the seed is the whole task.

### Assumptions
1. **No price concept for the entry fee or an additional dog** (`PriceConcept` is `MONTHLY_FEE, MAINTENANCE_FEE, PACK, SINGLE_CLASS`). The entry fee is the parameter `billing.entryFeePerDog` (product default 100 €, CATALEG_PARAMETRES PAR-29) applied through each plan's `entryFee` mode (`STANDARD`; `PERCENT 50` for THERAPY; `NONE` for the pack and single class). The additional dog is the family fare: a fifth plan `MONTHLY_FAMILY` (2 dogs, 90 €, admin-assigned, `showOnSignup: false`), as the Cànic's `ABONAT_FAMILIAR`. So the template has 5 plans, not 4.
2. **Starter amounts** are the Cànic's current ones (60, 90, 180, 10 €). The Cànic has no single class: 18 € = a tenth of the 10-session pack. A club edits them at D8.
3. **FAQ `published: false`**: the model has no such field (S05 FAQ: `active`). The placeholder entries are `active: true` so the club sees the skeleton at D11; their answer is the R-05-21b marker, which the app already treats as pending text.
4. **The template's modules** move from the `MINIM` preset to an explicit list (`FREE_TRAINING`, `BILLING`, `PACKS`, `SINGLE_CLASS`, `WAITLIST`, `FAQ`, `PUSH`): the template's own plans and prices are validated against its modules on `club:apply`. A destination on the CANIC preset must turn `SINGLE_CLASS` on before cloning `PLANS` (README; the smoke does it). No change to the clone API (task rule).
5. Step 5 says «the `{club}` variable»: the product seed's variable is `[[club_name]]`; the texts were already club-agnostic, so the JSON files did not change.
