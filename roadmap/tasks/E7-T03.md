## Steps
1. **`MessageTemplateService` + `MessageTemplateController`** (ADMIN only; `GET /message-templates` returns `items` in the D9 order — grouped by category `OPERATIONAL · PERSONAL · CLUB_CHANGES · CLUB_NEWS` — with `countsByCategory`, `caps` and `push` read from the `NotificationCatalog`, `variables[{key, label}]` with the label from `notif.variable.<key>` in the **admin's** locale and the code key as the stored value, and `lastChange` from the audit query (R-14-11)). `POST` creates a `CUSTOM` template (`category ∈ PERSONAL · CLUB_NEWS · CLUB_CHANGES`, member variables only, no action, 201). `GET /{id}` adds `titleI18n`, `bodyI18n`, `smsBodyI18n` maps and `seedDefault` (for the «Restaura el text per defecte» diff). `PUT /{id}` edits title, body, `smsBody`, icon, colour, matrix, `enabled` (+ `category` on `CUSTOM`) with `version` → `409 STALE_VERSION`; `DELETE /{id}` archives a `CUSTOM` one (204). Validation, with the exact code and status (`CATALEG_ERRORS.md` rule 0 wins over S11 §6): a matrix cell outside `caps` → `CHANNEL_NOT_ALLOWED` (**422**); `mandatory` (N-02, N-08a, N-15, N-17, N-32c, N-36) with `enabled = false` → `TEMPLATE_MANDATORY` (**422**); `reset` on a `CUSTOM` → `TEMPLATE_NOT_CATALOG` (**422**); `DELETE` on a `CATALOG` → `TEMPLATE_NOT_CUSTOM` (**422**); unbalanced ICU braces → `TEMPLATE_SYNTAX_ERROR` (**400**); a `[[var]]` outside the code's variables → `TEMPLATE_UNKNOWN_VARIABLE` (**400**); a missing `requiredVariables` entry (N-02 `link`, N-08a `admin_text`) → `VALIDATION_ERROR` (**400**) with `details.missingVariables[]` **and** a report proposal for `TEMPLATE_MISSING_VARIABLE` (E7-T01 already raised it — repeat it only if still unanswered); `smsBody` empty with an active SMS cell → `SMS_BODY_REQUIRED` (**400**); rendered `smsBody` over 160 GSM-7 characters with the sample data set → `SMS_BODY_TOO_LONG` (**400**); `body` over 2000 → `VALIDATION_ERROR`. Every change emits `MessageTemplateChanged{templateId, diff}`, writes `@Audited(CATALOG_CHANGED)` (`entityType = MessageTemplate`) inside the same transaction, sets `customized = true` when the text differs from the seed, and invalidates the per-club template cache. T-11-16.
2. **Preview and test send**: `POST /message-templates/{id}/preview {locale, draft?{title, body, smsBody}, sendTest?}` renders the **unsaved** draft with the fictional data set (`notif.preview.*` per locale: «Laura», dog «Duna» level «C», «dimecres 12 · 18:50 · B+C · Central», the rain admin text) and returns `{title, body, emailSubject, emailHtml, sms{text, length, segments, truncated}, warnings[]}` — `warnings` carries unknown variables and a truncated SMS instead of failing. With `sendTest: true` (the backlog's «envia prova») the same rendering is delivered **once** to the acting admin's own account through the engine, `dedupKey = test:{templateId}:{accountId}:{instant}`, audience `ADMINS`, channels APP + EMAIL only (never SMS, never another recipient), and the notification is stored in the log like any other.
