## Steps
1. `clubs/dashboard`: `DashboardQuery` (tenant from the JWT, club-local `today`, ISO week Mon–Sun, natural month), cached per club for `app.dashboard.cacheSeconds` and invalidated by consuming `SignupSubmitted`, `MemberValidated`, `SignupRejected`, `ClassCancelledByClub`, `ClassAutoCancelled`, `ClassAtRisk` (the last three exist in the event catalog; register consumers now, they fire from E4/E5); `generatedAt` in the response; impersonation token → `403 IMPERSONATION_DENIED`.
2. KPIs: `activeMembers` (R-14-02: `ACTIVE` count, `deltaThisMonth` = validated this month incl. readmissions − effective leaves this month), `classOccupancy` (R-14-03 over `ClassSession` of the week — **port** `ClassOccupancyQuery` with a null-object until E4: `percent = null`, `booked/capacity = 0`), `trainingBookings` (R-14-04 — port `TrainingBookingsQuery`, `null` block without `FREE_TRAINING`), `pendingSignups` (R-14-05: `PENDING` members or `ACTIVE` with a `PENDING` dog, `pendingDays`, `olderThanWarn` with `dashboard.pendingSignupAgeWarnDays`, `warnDays` echoed).
3. Cards: `riskReview` (R-14-06 `RiskCardBuilder` over the `RiskEvaluator` port + `ClassSession` repository port — with an in-memory double in tests reproducing the four mockup rows: `CANCELLED` (0), `CANCELLED` + Laura/Duna, `AT_RISK` + Pau/Blat, `WILL_CANCEL` with `reviewAt` = class day at `classes.riskReviewTime`; `PENDING_DECISION` when `riskAutoCancelSameDay = false`; `CLUB_MANUAL`/`DELETED` cancellations and `riskExempt` classes absent; window `[today, today + classes.riskLookaheadDays]`), `pendingSignups.items` (rows of R-14-05 with `shortName` «Marta R.», dogs `{name, breed, isAddDog}`, `planName` or «—», `paymentMethodType` only with `BILLING`, `warnings` of S04 R-04-18), `dogsByLevel` (R-14-07 through a shared `DogActivityQuery` — the same computation S06 R-06-06 will use: `ACTIVE` dogs of `ACTIVE` members per active level in `order`, `withRecentBooking` over the current week + `coverage.activeDogWeeks − 1` previous weeks via a `BookingActivity` port (null-object → 0 until E5), inactive levels → `others`; `null` when `levels.enabled = false`).
4. `GET /dashboard/counters` (R-14-08, cache 30 s): `pendingSignups`, `pendingRequests` (S13 ports: `InactivityPeriod`/`LeaveRequest` `REQUESTED` → null-object 0 until E8), `followUpUnread` (S10 port → 0 until E6).
5. Tests: T-14-01…06 as domain tests on the builders with the mockup numbers; T-14-11 integration with the Cànic seed (`GET /dashboard` JSON shape of §6, cache hit `generatedAt` unchanged within 60 s, invalidation after a validation, impersonation `403`); T-14-22 dashboard part (club B never sees A's numbers); T-14-23 (counters).
