# E1-T05 · OIDC provider: discovery, authorize + PKCE, userinfo, logout, JWKS rotation, seed clients

## Objective
Work package WP-01-D (backend part): AgilityHub ID as a standard OIDC provider for Learn, the AR app and any future product.

## Spec references
S01 R-01-11, R-01-16, §6 rows `/.well-known/*`, `/oauth2/authorize`, `/oauth2/userinfo`, `/connect/logout` · test **T-01-13** · `docs/decisions/ADR-010-*.md` (clients `clubs-app`, `clubs-admin`, `id-web`, `learn`, `ar-app`).

## Context to load
S01 R-01-11, R-01-16 · ADR-010 · the Spring Authorization Server config from E0-T09 · this file.

## Steps
1. Registered clients seeded from configuration (`core.oidc.clients[]` in `application.yml`, secrets from env, hashed bcrypt at load): public clients `clubs-app`, `clubs-admin`, `id-web`, `ar-app` (PKCE S256 mandatory), confidential `learn` (`client_secret`, scopes `openid profile email memberships accounts:write`).
2. `authorize` endpoint: code + PKCE, `prompt`, `login_hint`, `ui_locales`; unauthenticated → redirect to `apps/id` `/login?…` (host `id.agilitydoghub.com` from config) and back; consent skipped for first-party clients.
3. `userinfo`: `sub, email, email_verified, name, locale, memberships[{clubId, clubName, roles}]` with scope `memberships`.
4. JWKS rotation: two live RSA keys with `kid`, command `identity:rotate-keys` (new signing key, previous kept for verification), keys stored encrypted in Mongo (`signing_keys`) with the master key from env; `/.well-known/jwks.json` with `Cache-Control`.
5. `GET /connect/logout` (RP-initiated) revoking the `id.*` session cookie; cookies `Secure` + `HttpOnly` + `SameSite=Lax`.

## Verification (run all; evidence = command + exit code + last 40 lines; long outputs → `roadmap/evidence/<ID>/*.log`)
- `./mvnw -q verify` → green with T-01-13 (discovery document valid; `authorize` without PKCE for a public client → 400; full code + PKCE flow with a test client → `id_token` with the expected claims; `userinfo` scopes).
- Script `bin/oidc-smoke` (curl/python) performing the code flow against a local run — paste its output.

Discovery + authorize + token + userinfo + logout + JWKS rotation tested; seed clients documented in README (no secrets).
