# E0-T08 · Backend i18n: ICU message source (ca/es/en), response locale resolution, ClubFormats

## Objective
Messages (errors, later notifications) in the three product locales with ICU plural/gender support, and the club-aware formatting helpers.

## Spec references
`docs/specs/00-transversal/CONVENCIONS_I18N.md` · `docs/decisions/ADR-011` · S02 T-02-17 (back part: duration formats).

## Context to load
CONVENCIONS_I18N · ADR-011 · this file.

## Steps
1. ICU `MessageSource` (icu4j `MessageFormat`) over `src/main/resources/messages/messages_{ca,es,en}.properties` (UTF-8). Locale resolution order for a response: the authenticated account's `locale` → `Accept-Language` restricted to `Club.locales` → `Club.defaultLocale` → `ca`. Expose `LocaleContext.current()` for services.
2. Messages for **every** `ErrorCode` in the three files (`error.<CODE>`); wire them into the error handler of E0-T04.
3. **Parity test**: the three files have the same key set and no empty value. **ICU test**: `{count, plural, one {1 gos} other {# gossos}}` and a gender select render correctly in `ca`.
4. Idempotency error code: replace the temporary use of `STALE_VERSION` for `Idempotency-Key` conflicts (E0-T04) by `IDEMPOTENCY_KEY_REUSED` (409, `details.reason = DIFFERENT_REQUEST | IN_PROGRESS`; catalog updated 2026-09-06) and add its messages in the three locales; update `IdempotencyIT` accordingly.
5. `ClubFormats(clubConfig)`: `formatDate`, `formatTime`, `formatDateTime`, `formatDuration` («2 h», «30 min», «4 h abans»), `formatMoney` («45,00 €» / «€45.00»), in the club's time zone and the recipient's locale; used later by notification templates.

- `curl` an endpoint returning an error with `Accept-Language: es` → Spanish `message` (paste).
