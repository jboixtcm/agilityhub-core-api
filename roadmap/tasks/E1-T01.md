# E1-T01 · S01 contract: OpenAPI of the identity endpoints, ErrorCode additions, snapshot

## Objective
The complete API contract of AgilityHub ID in the snapshot before the implementation tasks start, so the web repo can generate types in parallel.

## Spec references
`docs/specs/S01-agilityhub-id-i-acces.md` §6 (every endpoint with roles, bodies, responses and error codes), §3 (entities), §5 (states) · `docs/specs/00-transversal/CATALEG_ERRORS.md` (S01 row) · `docs/specs/00-transversal/CONVENCIONS_API.md`.

## Context to load
S01 §3, §5, §6 · CATALEG_ERRORS · CONVENCIONS_API · the existing `docs/openapi/openapi.json` and `OpenApiSnapshotTest` (E0-T12) · this file.

## Steps
1. Controllers with request/response DTOs and springdoc annotations for: `POST /oauth2/token` (document the custom grants and their form parameters as an `x-grants` extension), `GET /.well-known/openid-configuration`, `/.well-known/jwks.json`, `POST /oauth2/revoke`, `GET /oauth2/userinfo`, `GET /connect/logout`, `POST /auth/magic-link`, `POST /auth/handoff`, `GET /me`, `PATCH /me`, `PUT /me/password`, `PUT /me/profile`, `GET /me/sessions`, `DELETE /me/sessions/{id}`, `GET/PUT /me/onboarding`, `POST /members/{id}/impersonation-token`, `POST /platform/accounts`, `PUT /accounts/{id}/password`. Bodies exactly as S01 §6. Create the controllers now with real method signatures and `@Operation` docs; bodies not yet implemented throw `UnsupportedOperationException` (mapped to `501`) until E1-T02…T06 fill them — the point is a stable contract.
2. `ErrorCode`: every S01 code of the catalog (`INVALID_CREDENTIALS`, `LOGIN_LOCKED`, `NO_MEMBERSHIP`, `MEMBERSHIP_SUSPENDED`, `ACCOUNT_BLOCKED`, `MAGIC_LINK_INVALID`, `HANDOFF_INVALID`, `REFRESH_EXPIRED`, `PROFILE_NOT_AVAILABLE`, `PASSWORD_TOO_SHORT`, `PASSWORD_MISMATCH`, `PASSWORD_COMPROMISED`, `LOCALE_NOT_SUPPORTED`, `IMPERSONATION_DENIED`, `EMAIL_EXISTS`, …) — the catalog contract test must stay green.
3. Schemas `Me` (R-01-15 shape), `TokenResponse`, `Profile`, `Session`, `OnboardingState`, `HandoffResponse`, `ImpersonationTokenResponse`, `PlatformAccountRequest`.
4. `bin/openapi-snapshot` → commit `docs/openapi/openapi.json`; lines in `docs/openapi/CHANGELOG.md`.

## Verification (run all; paste full output in the report)
- `./mvnw -q verify` green (contract tests, catalog tests).
- `jq '.paths | keys' docs/openapi/openapi.json` → all routes above.
- `bin/openapi-snapshot && git status --short docs/openapi` → clean on a second run.

## Definition of Done
Contract complete and committed · error codes present · snapshot clean.
