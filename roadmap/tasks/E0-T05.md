# E0-T05 · platform: Club, parameters, ParameterCatalog, ClubConfigService cache, CountryProfile, TenantContext, /branding

## Objective
Work package WP-02-A: multi-tenant resolution by host/JWT and the per-club configuration with **every** parameter key of the catalog, plus the public `/branding` endpoint the front apps bootstrap from.

## Spec references
`docs/specs/S02-club-configuracio-i-parametres.md` §3–6 and §9 (tests **T-02-01, T-02-02, T-02-03, T-02-04, T-02-06, T-02-07**; T-02-15/16 back part) · `docs/specs/00-transversal/CATALEG_PARAMETRES.md` (all keys, main tables + Annex A) · `docs/specs/00-transversal/CATALEG_MODULS.md` · `docs/MODEL_DADES_PLATAFORMA.md` §2 (CLUB).

## Context to load
S02 (whole) · the three catalogs · MODEL_DADES_PLATAFORMA §2 · `docs/pantalles/escriptori/D11-parametres.png` (to see the parameter blocks) · this file.

## Steps
1. `Club` (collection `clubs`, global): `slug`, `name`, `locales[]`, `defaultLocale`, `timeZone`, `currency`, `countryProfile`, `domains[] {host, status (PENDING|VERIFIED), verifiedAt, primary}`, `theme {colors {primary, primaryFg, surface, surface2, text, textMuted, border, success, warning, danger, info}, logoUrl, markUrl, fonts, mode (AUTO|LIGHT|DARK)}`, `modules[]`, `paymentProviders[]`, `legal {privacyPolicyUrl, policyVersion}`, `status (ONBOARDING|ACTIVE|SUSPENDED|CLOSED)`, `version`, timestamps. Unique indexes on `slug` and `domains.host`.
2. `ParameterCatalog` loaded from `src/main/resources/parameters/catalog.yaml` — one entry per key with `type` (int, bool, duration, time, money, enum, localizedText, json, list…), `default`, `block` (D11 block), `labelKey`, `helpKey`, `constraints`, `modules[]`, `scope`, `editableBy`. Write the YAML by transcribing `CATALEG_PARAMETRES.md` completely (main tables **and** Annex A). **Test T-02-03**: parse the markdown tables of the catalog document and assert keys, types and defaults match the YAML — any divergence fails.
3. `Parameter` (collection `parameters`, tenant): `{clubId, key, value, scopeRef?, history[] {value, at, by, reason}}`, unique index `{clubId, key}`. Resolution rule R-02-03 `scopeRef ?? club ?? default` (T-02-01), validators by type (T-02-02; invalid → `PARAMETER_INVALID`), an invalid stored override is ignored and logged (`ParameterInvalidOverride`).
4. `ClubConfigService.get(clubId)` → immutable `ClubConfig` (club + resolved parameters + modules), Caffeine cache (5 min) invalidated by handlers of `ClubConfigChanged` and `ParameterChanged` (outbox events from E0-T04); typed accessor `config.get("bookings.lateCancelThresholdMinutes", Integer.class)`; implements `TimeZoneProvider` for `ClubClock`.
5. `CountryProfile` (`ES`, `GENERIC`): `idDocumentTypes` (`ES`: DNI, NIE, PASSPORT), national-id validation (DNI/NIE check letter), phone normalisation to E.164 with the default prefix, IBAN validation (mod-97 + per-country length), postal code → locality lookup (`src/main/resources/country/es/postal-codes.csv` from **GeoNames postal codes for ES**, CC BY 4.0 — add the attribution to README; `GENERIC` has no lookup), date/time formats. **T-02-04**: `12345678Z` valid, `12345678A` invalid, `X1234567L` valid NIE, `08349` → «Cabrera de Mar», `612345678` → `+34612345678`; `GENERIC` performs no format validation.
6. Tenant: `TenantContext` (ThreadLocal, cleared at the end of each request) + `TenantFilter`: `/api/v1/platform/**` and `/api/v1/health` run **without** tenant; authenticated requests take `clubId` from the JWT claim and, if the request host belongs to a different club → `403 TENANT_MISMATCH`; unauthenticated public routes (`/api/v1/branding`, `/api/v1/public/**`, `/oauth2/**`) resolve the tenant from the `Host` header against `Club.domains` (cached) or `404 UNKNOWN_HOST`; in profile `local` the header `X-Club-Host` overrides the host (T-02-06). `TenantRepository<T extends TenantEntity>` (adds `clubId` to every query and write; throws if no tenant is set) and `GlobalRepository<T>`; **test**: a tenant repository cannot read another club's document even by id.
7. `GET /api/v1/branding` (public, per host): `{ club {slug, name}, theme, locales, defaultLocale, timeZone, currency, countryProfile {code, idDocumentTypes, phonePrefix}, modules[], signup {enabled}, status, legal {privacyPolicyUrl} }` — no business parameter, no secret; `ETag` + `304` (T-02-07). `GET /api/v1/manifest.webmanifest` (name, short_name, colors, icons of the club).
