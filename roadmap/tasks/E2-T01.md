# E2-T01 · E2 contracts: parameters API, census, catalogs, audit/exports (OpenAPI + ErrorCode + snapshot)

## Objective
Every E2 endpoint in the OpenAPI snapshot with its schemas, list extensions and error codes, before the implementation tasks, so the front tasks can start on mocks.

## Spec references
`docs/specs/S02-*.md` §6 (`/parameters*`, `/club*`, `/country-profile/postal-codes`) · `docs/specs/S03-cens-abonats-gossos.md` §6 (members, dogs, family groups, `/me/*`, saved views, exports) · `docs/specs/S05-catalegs.md` §6 (levels, rings, instructors, administrators, plans, prices, faq, `/public/{clubSlug}/plans`) · `docs/specs/S14-*.md` §6 (`/audit-entries`, `/exports`, `/dashboard` schemas only) · `docs/specs/00-transversal/CONVENCIONS_API.md` §3–5 (universal list contract: `page,size,sort,q,filter=<field>:<op>:<value>`, `fields`, `x-filterable`, `x-sortable`, `x-columns`, `filter-values`) · `CATALEG_ERRORS.md` rows S02, S03, S05, S14.

## Context to load
The §6 tables above · CONVENCIONS_API · CATALEG_ERRORS · this file.

## Steps
1. Controllers with DTOs and springdoc annotations for all routes of the four §6 tables (bodies not yet implemented throw `UnsupportedOperationException` → `501`); list endpoints declare `x-filterable`, `x-sortable`, `x-columns` extensions exactly as the specs list them (they drive the universal filter in the front).
2. Schemas: `Member`, `MemberListItem`, `MemberInstructorView`, `MemberOverview`, `Dog`, `DogListItem`, `FamilyGroup`, `MeDogs`, `MeProfile`, `SavedView`, `Level`, `Ring`, `Instructor`, `Administrator`, `Plan`, `Price`, `PublicPlan`, `FaqEntry`, `Parameter`, `ParameterHistoryEntry`, `ClubSettings`, `AuditEntry`, `AuditEntryListItem`, `ExportJob`, `ListPage<T>` (generic page shape of CONVENCIONS_API).
3. `ErrorCode` additions from the four catalog rows (e.g. `MEMBER_NOT_ACTIVE`, `BOOKING_BLOCK_NOT_ACTIVE`, `DOG_HAS_FUTURE_BOOKINGS`, `TARGET_MEMBER_NOT_ACTIVE`, `SAME_MEMBER`, `FAMILY_GROUP_MEMBER_TAKEN`, `DUPLICATE_NAME`, `LEVEL_IN_USE`, `ORDER_INCOMPLETE`, `INSTRUCTOR_IN_USE`, `LAST_ADMIN`, `PLAN_IN_USE`, `PRICE_LOCKED`, `UNKNOWN_PARAMETER`, `PARAMETER_INVALID`, `PLATFORM_ONLY`, `TIMEZONE_CHANGE_BLOCKED`, `EXPORT_LIMIT`, …) — catalog contract test green.
4. `bin/openapi-snapshot`; `docs/openapi/CHANGELOG.md`.
