# E11-T08 · The api correction pass, part 2

## Objective
Fix the incidences that the reviews of E10-T04, E10-T03 and E11-T06 and the upgrade E11-T07 found after E11-T02 had started: INC-65, INC-66, INC-67 and INC-68 of `docs/INCIDENCIES_OBERTES.md`, plus the Sentry setting that E11-T07 reported (ruling E131, size M). ## Steps
1. **INC-68 first (prices).** A `Price` written whole (`PriceRepository.insert`, any `save`) stores `validFrom`/`validTo` as BSON dates, despite `@Field(targetType = STRING)`; a partial update stores strings.
   - Find every read that filters or compares these fields, in queries and in code.
   - Write a test showing whether a price written each way is chosen correctly for a billing date.
   - Store one type everywhere (the one the model gives), and convert what a seed or an earlier write left in the other type (a startup migration or the seed itself; production is not live yet).
   - If the fix would store data in a way the model does not describe, set the task `blocked` with the proposal.
2. **INC-67 (rate limits):**
   - In `SecurityInventoryIT`, every published anonymous operation that is not a `GET` has a `RateLimits.Route`, or is on a short, documented exempt list.
   - The `STRIPE_WEBHOOK` bucket is keyed by `clubId:ip`.
   - With a bearer token, `CHECKOUT_STATUS` counts per account (`jwt.getName()`).
3. **INC-66 (domains):**
   - `JndiDomainDns` returns the `A` values its JNDI retry finds, or throws `LookupFailed` when the two resolvers disagree, with the new case in `T_17_03_R_17_03_anAddressLookupTellsNoAddressFromNoAnswer`.
   - `docs/DEPLOY.md`: the first option for trusted domains says to check the records with `dig` before the first re-check is due, and a domain that is already `BROKEN` comes back with [Verifica].
   - `ClubRepository.save` either documents that it relies on the caller's transaction, or merges atomically.
4. **INC-65 (support and idempotency):**
   - `HEAD` in `SupportAccessService.RESTRICTED`, or a `HEAD` case in `SupportAccessIT`.
   - The club check of `IdempotencyFilter` works without opening a tenant, or has a comment and a test with a club's `Host`.
   - Leave the fully qualified `@SupportRestricted` as it is: it touches 22 handlers that other lanes are editing.
5. **Sentry:** `sentry.logs.enabled: false` in `application.yml` instead of `sentry.enable-logs` (which binds to nothing), with a test that the property binds.

Each fix comes with a test that fails before it. Do not edit `docs/INCIDENCIES_OBERTES.md`: the organizer marks the incidences resolved when it verifies the task.
