### Assumptions
1. **Dependency direction.** The task says `clubs.followup → clubs.census.application`, but census already depends on `clubs.followup.application.AttachmentService`, and `E0_T01_contextsHaveNoCycles` failed. So the follow-up guards read a dog's owner through the shared port `DogOwnerAccess.ownerOf`, which census implements, as `AttachmentService` already does.
   - `clubs.bookings` ⊬ `clubs.followup` and `platform` ⊬ `clubs` are new ArchUnit rules.
2. **Impersonation.** It is accepted exactly where the task lists: `/me/history`, `GET /tasks`, the completion, and the member's own `INSTRUCTOR_NOTE` attachments. `GET /tasks/{id}` rejects it, as the task says.
   - `GET /attachments` also accepts it for `TASK`, because the member reads their task attachments (R-10-11); `DOG_OBSERVATIONS` is 404 for any member.
   - `DELETE /attachments/{id}` accepts it only for `INSTRUCTOR_NOTE`.
3. **Upload URLs for the new purposes are live.** `POST /attachments/upload-url` for `TASK`/`DOG_OBSERVATIONS` answers 201 to INSTRUCTOR/ADMIN, with the same type and size rules and TASKS required. Only registration, the list and the removal are 501, as step 6 says.
   - An INSTRUCTOR alone still gets 403 on the S03/S07 purposes, as before.
4. **`attendanceStatus` total** = `counters.booked + attendanceSummary.notified` (live bookings + seat-releasing NOTIFIED rows, R-10-02).
   - A `NOTIFIED{afterClassEnd}` row keeps its booking ACTIVE and would count twice. E6-T02 may need to count it apart; see the questions.
   - A DRAFT class is `NONE`, a CANCELLED class is `CLOSED`, and a class without rows inside the window is `DONE`.
5. **Model vs spec (ruling in the task).** `Attendance` stores `noShowNotice{queuedAt, eventId, sentAt}`, `markedBy{accountId, role, displayName}` and `notice.late`; `noticeSentAt ≡ noShowNotice.queuedAt`. `classDate` is stored as `YYYY-MM-DD` text, so `classDate < today` compares correctly.
6. **Schema names.** `CardAttachment {id, name, mimeType, url}` is the 4-field card attachment of the S10 example: `NoteAttachment` already exists in census with 6 fields. `AttachmentResponse` is renamed `Attachment` (task schema name).
   - `FollowupPage` has exactly the universal `ListPage` fields.
   - `CardDog.handlerName` (nullable) is added for R-10-00 «{guia} + {gos}» on 22/D13. It is not in the §6 example.
7. `TASK_ALREADY_DONE` follows rule 0 (422), although S10 §6 writes 409.
8. `/instructor/day` also accepts `instructorId=me`. An unknown or foreign `instructorId`/`ringId` is 404 on the day and the week, and `format` other than `pdf` is 400.
