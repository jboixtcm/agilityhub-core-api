## Steps
1. **`clubs/signup/domain`**: `IdDocumentValidator` (ES DNI/NIE check letter, passport only when DNI/NIE empty → `ID_DOCUMENT_AMBIGUOUS`; GENERIC free ≥ 4) — extend the existing census validator if it already covers this, `PhoneNormalizer` (reuse E2-T06), `EmailRules` (RFC-lite, lower-case, distinct, first = primary), `PostalCodeTowns` (0/1/>1 semantics over the E2-T02 dataset; GENERIC → always 0, free town).
2. `FirstMonthCalculator` (R-04-15): inputs club-local today, `signup.firstMonthSplitDay`, monthly price → options A/B with labels' data (`startDate`, amount HALF_UP of `amountMinor/2`), proposed `nextInvoiceDate` = day `billing.nextInvoiceDayOfMonth` of the month after `startDate`; T-04-05 table including the `2026-08-15T22:30:00Z` instant (club time zone decides the day).
3. `UpfrontLines` (R-04-14): per plan type + `BILLING` flag + mode (public / add-dog: `ENTRY_FEE` + `ADDITIONAL_DOG_FEE` of the current month, or entry only with the «1st of next month» option when today ≤ `billing.upfrontCutoffDay`); `UpfrontAllocator` (R-04-16): cascade `ENTRY_FEE → FIRST_MONTH/PACK`, `PAID/PARTIAL/DUE`, `UPFRONT_AMOUNT_EXCEEDS_DUE`; T-04-06, T-04-07.
4. `FamilyHolderMatcher` (R-04-12): normalisation (lower-case, accents stripped, spaces compacted), all tokens of `holderName` (≥ 2) contained in the member's full name **and** a non-`LEFT` dog named `dogName`; exactly one → `FOUND` + `holderDisplayName` («Marta R.»); `INACTIVE` dogs do not count, `PENDING` holders do; T-04-08. Family fare proposal (R-04-13): `FAMILY` price if the resulting group has ≥ 2 non-`LEFT` dogs, else `STANDARD` with the `billing.familyDiscountPercentFromSecondDog` hint.
5. `SignupPlanCatalog` (R-04-09): `Plan.active ∧ showOnSignup` ∧ type allowed by modules (`PACK`→`PACKS`, `SINGLE_CLASS`→`SINGLE_CLASS`), catalog order, `STANDARD` current price, entry fee resolution (`Plan.entryFee.amount` ?? `billing.entryFeePerDog × percentOfStandard/100` ?? MONTHLY 100 € / PACK·SINGLE 0), no amounts without `BILLING`; T-04-09.
6. Consent versioning (R-04-17): `ConsentPolicy.check(request, club.legal)` → `400` (not accepted) / `CONSENT_VERSION_OUTDATED`; add-dog mode only re-asks when the last `PRIVACY_POLICY` entry is older than `legalTextsVersion`.
7. State machines as pure functions with the transition table of S04 §5 (`SignupState` for `Member.status` + `signup`, `UpfrontPaymentStatus`), used by E3-T03; gender ICU snapshots for N-02 and the image warning (T-04-10) through the existing `IcuMessageSource` (ca/es/en).
