## Steps
1. `AccountService.getOrCreate(email, name, locale, source)` — the only creation path (R-01-01); email normalisation test T-01-01.
2. `MagicLinkToken` (collection `magic_link_tokens`: SHA-256 hash of a 32-byte token, `purpose LOGIN|RESET|WELCOME|ACCESS_RESEND|RECOGNITION`, `expiresAt = now + auth.magicLinkMinutes`, single use, max 3 alive per purpose+account): `POST /auth/magic-link` always `202` (neutral timing for unknown emails), event `MagicLinkRequested` → email N-25 through the `SYSTEM` mail path (E1-T03; until it lands, a `FakeEmailSender`), grant `urn:agilityhub:grant:magic-link` exchanges the token for tokens (T-01-03, T-01-08).
3. Refresh tokens (collection `refresh_tokens`: opaque 32 bytes hashed, `familyId`, `clientId`, `deviceLabel`, `expiresAt` sliding by `auth.sessionDays`, `status ACTIVE|ROTATED|REVOKED`): rotation on every use, reuse of a rotated token revokes the family + `SecurityEvent REFRESH_TOKEN_REUSED` (T-01-04); `POST /oauth2/revoke`; global revocation via `tokenFamilyVersion` (T-01-16); `GET /me/sessions`, `DELETE /me/sessions/{id}`.
4. Lockout R-01-08: 5 failures / 15 min → `lockedUntil` progressive ×2 up to 24 h, `429 LOGIN_LOCKED` + `Retry-After`, `SecurityEvent LOGIN_LOCKED`; magic link never locked (T-01-06; T-01-15 with the E0-T11 limiter).
5. `PUT /me/password` (R-01-05): `current` required only when a hash exists, min length `auth.passwordMinLength`, not equal to the email, HIBP k-anonymity check when `auth.checkCompromisedPasswords` (2 s timeout, fail-open + log), argon2id, `tokenFamilyVersion++`, event `PasswordChanged` → N-26 (T-01-09).
6. Profiles R-01-07: `PUT /me/profile {activeProfile, remember}` → new access token; `PROFILE_NOT_AVAILABLE`; `defaultProfile`/`rememberProfile` on the membership (T-01-05, T-01-10).
7. `GET /me` aggregate exactly as R-01-15 (`account`, `membership {clubId, roles, activeProfile, profiles[], memberId, instructorId, defaultProfile, rememberProfile}`, `impersonation?`, `features`), `PATCH /me {locale?, name?}` (`LOCALE_NOT_SUPPORTED` outside product locales), never exposing `passwordHash`/`security` (T-01-17).
8. Audit: `LOGIN`, `LOGIN_FAILED`, `PASSWORD_CHANGED`, `SESSION_REVOKED` actions covered by `@AuditCovers` tests.
