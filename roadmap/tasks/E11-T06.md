## Steps
1. **Sentry captures handled internal errors (E11-T03 review #1).** Set `sentry.exception-resolver-order` to `Ordered.HIGHEST_PRECEDENCE` (or capture explicitly in `ApiExceptionHandler.unexpected` with the trace id as a tag — one of the two, documented). Test: a DSN-enabled context with an in-memory `ITransport` receives exactly one event for a handled 500, scrubbed by `beforeSend`, carrying the response's `traceId`; nothing for a 4xx.
2. **One canonicalisation for the account quota (review #2).** `RateLimitFilter` uses `Email.normalize` for `TOKEN_ACCOUNT`. Test: `josé@example.test` composed and decomposed (NFC/NFD) from two IPs share one limit.
3. **The phone exclusion (review #3).** `LogPrivacy` allows up to two separators of `[ .()-]` between digit groups. Regression for `+1 (202) 555-0100`, `(202) 555-0100`, `+34 600 00 00 00` on both the console formatter and the Sentry message path; the UUID carve-out still holds.
4. **Local compose without the URI override (E11-T04 review #1).** `compose.prod.local.yaml` gives `core` the production wiring (`MONGODB_HOST`, credentials, authentication database, replica set) and keeps `SPRING_DATA_MONGODB_URI` only on the seed/host fixture. Re-run the Caddy/health/branding checks of E11-T04's rehearsal under that configuration and record the log.
5. **`system.views` out of the inventory (review #2).** `backup.py` follows mongodump's namespace rules (no `system.views`). Backup/restore regression with a database that holds a real view: the namespace comparison passes and the view is recreated.
6. **The recovery env file in the runbook (review #3).** `docs/DEPLOY.md` step 4 runs `bin/restore-mongo --verify` with the recovery environment file (the identity with `GetObject`), never with `core.env`; the MinIO rehearsal uses the same split so the mismatch would show.
7. **E8's routes in the security inventory.** Every S12/S13 route published by E8 (billing, invoices, remittances, checkout, Stripe webhook, `/me/card-setup`, packs, inactivity, leave) joins E11-T03's inventory with INC-45's global check (role × endpoint from `MATRIU_PERMISOS`, cross-tenant probe), and the anonymous ones (checkout return polling with `X-Signup-Token`, the Stripe webhook) get their own rate-limit rows per `CONVENCIONS_API` §9 — replacing the shared infrastructural quotas E11-T03 left on them.
8. **PITest on `payments` and the full-package gate.** `payments` joins `targetClasses`; the scoring follows E11-T03's adopted proposal (assertion kills over all generated mutations, uncovered mutants in the denominator). Survivor triage: each surviving mutant either gets a test or a one-line reason in the report. Record the per-package kill ratios; the threshold is PLA_BACKEND §9's.
