# E0-T03 · CI on GitHub Actions with coverage thresholds, secrets scan and OpenAPI diff hook

## Objective
Every push to `main` runs build, tests (with Docker for Testcontainers), coverage thresholds, architecture rules, secret scanning and (once E0-T12 exists) the OpenAPI snapshot diff.

## Context to load
`AGENTS.md` · `docs/PLA_BACKEND.md` §9 · this file.

## Steps
1. `.github/workflows/ci.yml`: `ubuntu-latest`, `actions/setup-java` (temurin 21, Maven cache), `./mvnw -B verify`, upload the JaCoCo HTML report as an artifact, `gitleaks/gitleaks-action` for secrets, and a step that runs `git diff --exit-code docs/openapi/openapi.json` **only if** that file exists (`if: hashFiles('docs/openapi/openapi.json') != ''`).
2. JaCoCo `check` in `pom.xml`: `domain` + `application` packages **≥ 85 % lines / 80 % branches**; `api` packages ≥ 70 % lines; `persistence` reported but not enforced; exclude `*Config`, `*Application`, generated DTOs. Make the thresholds fail the build.
3. `.github/dependabot.yml` (maven + github-actions, weekly).
4. README: document the branch protection Jordi must enable on `main` (1 review + CI green) — you cannot enable it yourself.

## Verification (run all; evidence = command + exit code + last 40 lines; long outputs → `roadmap/evidence/<ID>/*.log`)

- Prove the threshold works: in a throw-away commit add an untested class with branches in a `domain` package, run `./mvnw -q verify` locally → build FAILS on the JaCoCo check; revert the commit (paste both outputs).
