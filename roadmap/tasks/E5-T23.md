# E5-T23 · The Cànic's cash payment instructions, and the E5-T21 review

The Cànic's definition has none since E3-T14, so the real core shows no such paragraph. Jordi confirmed the text of the approved mockup 19 on 26-09, account and Bizum included. ## Steps
1. **The Cànic's cash payment instructions (Jordi, 26-09).** `seeds/club-canic.yaml` gets `paymentProviders.MANUAL.instructions`, word for word as Jordi confirmed:
   - ca «El pagament de l'entrada i el mes en curs (o el proper) és necessari per a la validació de l'alta. Pot fer-se per transferència al compte ES08 2100 0416 5702 0016 4955 (Club d'Agility Cànic) o per Bizum al 607 475 945.»;
   - es «El pago de la entrada y del mes en curso (o del siguiente) es necesario para la validación del alta. Puede hacerse por transferencia a la cuenta ES08 2100 0416 5702 0016 4955 (Club d'Agility Cànic) o por Bizum al 607 475 945.».
   
   Tests:
   - `club:apply` stores them, and a second run reports 0 changes;
   - `GET /signup` sends them in `paymentMethods[MANUAL].instructions`, in ca and in es;
   - `bin/e3-smoke` stays green twice.
   
   These are the club's public payment details, which the approved mockup shows. They are not a member's personal data.
2. **The card requirement only when the card changes (E5-T21 review #1).** With `signup.requireDogDocumentAtSignup=true`, the check applies only when the card's file keys differ from what D2's view shows. An edit that sends back the view (or changes another field while echoing the documents) never gets `422 DOG_DOCUMENT_REQUIRED`. IT with the parameter on: a pending public-signup dog whose card is `PENDING`.
3. **A removed key at submission (review #2).** The E5-T21 entry of `docs/openapi/CHANGELOG.md` says that a removed key is refused at submission too (`POST /signup` for a readmission, `POST /me/dogs/signup`). Add a submission IT with a removed key of the reused dog's own card.
4. **The backoff Javadoc (review #3, question 1).** `TransactionRetriesTest`'s class Javadoc says «every S05–S09 writer». The S01 and S04 writers keep their own growing backoff by design: they retry many more times.
5. **Optional (review #4).** A reused dog's merge takes only the types whose keys differ from D2's view, as the public path does.
