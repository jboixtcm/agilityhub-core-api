## Steps
For each finding, first write the test that fails without the fix. If a finding turns out to be wrong, keep the code, add the test that proves it, and say so in the report.
1. An interrupted production import can resume: a `RUNNING` run left by a crash is picked up or safely restarted, without duplicating what it already committed (E8-T06 review #1, `MigrationRunRepository.java:15`).
2. The reset's «no writes after the production load» check and the deletion share one write lock, so a write in between is never lost (#2, `MigrationResetService.java:27`).
3. Reapplying a changed future leave date also updates `LeaveRequest.decision.effectiveDate` (#3, `PlayoffPlanner.java:251`).
4. Billing-reminder days 29–31 clamp to the month's last day, as the job framework does elsewhere (#4, `BillingReminderJob.java:26`).
5. The whitespace check covers the task's committed range, not only uncommitted changes (#5, `roadmap/evidence/E8-T06/check-handoff.py:12`).
6. `bin/security-scan` rejects a suppression whose `recorded` date is in the future (E8-T08 review #1, `bin/security-scan:44`).
