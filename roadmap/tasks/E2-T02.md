# E2-T02 · Parameters and club settings API (S02 WP-02-B): /parameters*, /club*, opening hours, holidays, postal codes

## Objective
Work package WP-02-B: the admin can read and change every parameter and the club settings, audited and with history.

## Spec references
S02 R-02-04 (validation, history), R-02-07 (modules self-service, dependencies), R-02-09 (opening hours), R-02-11 (status), R-02-12 (roles), R-02-13 · tests **T-02-08, T-02-09, T-02-10, T-02-11, T-02-15, T-02-16** · `docs/DECISIONS_PENDENTS.md` A23 (self-service modules: FAQ, PUSH, LEARN_LINK) · B23 (holidays = list of dates with label).

## Context to load
S02 §4, §6, §11 · CATALEG_PARAMETRES · CATALEG_MODULS · E0-T05/T06 code · this file.

## Steps
1. `GET /parameters` (all keys with resolved value, default, block, `lastChange`), `GET /parameters/{key}` (+ `history[]`), `PUT /parameters/{key} {value, reason?}` (type validation → `PARAMETER_INVALID`, unknown → `UNKNOWN_PARAMETER`, `editableBy` respected → `403 PLATFORM_ONLY`), event `ParameterChanged`, audit `PARAMETER_CHANGED` with before/after, `ClubConfig` cache invalidated (T-02-08).
2. `GET/PUT /club` (name, contact, theme fields the club may edit; console-only fields → `PLATFORM_ONLY`; `timeZone` change blocked when classes exist → `TIMEZONE_CHANGE_BLOCKED` T-02-15), `PUT /club/modules/{module} {enabled}` (self-service list only; dependency validation → `MODULE_DEPENDENCY`; T-02-09), `GET/PUT /club/opening-hours` (per weekday `{open, close}`, `open ≥ close` → `PARAMETER_INVALID` T-02-16), `GET/PUT /club/holidays` (`[{date, label}]`).
3. `GET /country-profile/postal-codes/{code}` (E0-T05 lookup) and `GET /country-profile` (id types, phone prefix, formats).
4. Roles: ADMIN only for writes; INSTRUCTOR/MEMBER → 403 (T-02-11); club B never sees club A (tenant test).
