# E0-T11 · Security baseline: rate limiting, dynamic CORS per club, headers, SecurityEvent, actuator isolation

## Objective
The security defaults that must exist before any real endpoint ships.

## Spec references
S01 R-01-08 (rate limits; test **T-01-15** partially — the `/oauth2/token` limit) · S14 §5 (`SecurityEvent`) · `docs/specs/00-transversal/CONVENCIONS_API.md` §9.

## Context to load
S01 R-01-08 · S14 §5 · CONVENCIONS_API §9 · this file.

## Steps
1. Bucket4j rate limiting: per IP on public routes (`POST /oauth2/token` 30/min, `GET /branding` 120/min, `/api/v1/public/**` 60/min) and per account on `/api/v1/me/**` (600/min); `429 RATE_LIMITED` (standard shape) with `Retry-After`; limits configured under `core.security.rateLimits` in `application.yml`; disabled in the `test` profile except in the test that exercises them.
2. Dynamic CORS: allowed origins = verified club hosts (`Club.domains`, all hosts in `local`) + platform hosts (`id.`, `clubs.`, `clubsadmin.agilitydoghub.com` from configuration); no credentials (tokens travel in headers); cache the origin lookup.
3. Headers: HSTS (prod profile), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, a basic CSP for the HTML pages served by the authorization server, no `Server` header.
4. `SecurityEvent` (collection `security_events`, global): `{ at, type (LOGIN_FAILED|LOCKED|RATE_LIMITED|TOKEN_REUSE|TENANT_MISMATCH|…), accountId?, clubId?, ip, details }` written by the filters and the password grant; TTL 1 year.
5. Actuator only on `management.server.port=8081` (not exposed by compose to the host) with `health`, `info`, `prometheus`.
6. Add `gitleaks` config (`.gitleaks.toml`) if any allow-list is needed (e.g. the test bcrypt fixture).

## Verification (run all; evidence = command + exit code + last 40 lines; long outputs → `roadmap/evidence/<ID>/*.log`)
- `./mvnw -q verify` → green with `RateLimitIT` (31 requests to `/oauth2/token` in a minute → 429 with `Retry-After`), `CorsIT` (club origin allowed; unknown origin has no CORS headers), `SecurityHeadersIT`, `SecurityEventIT` (failed login writes `LOGIN_FAILED`).
- `gitleaks detect --no-git -v` (or the CI step) → no findings.
- `curl -sI localhost:8081/actuator/health` from inside the compose network works, and `curl -sI localhost:8081` from the host fails (port not published) — paste.
