# E8-T09 · E8 review follow-ups before the gate

## Objective
Fix what the reviews of E8-T04's round 3 and E8-T05's round 2 found. They are money and census defects, so they are fixed before the E8 gate (ruling E92). Each finding, with its example, is in the review it comes from.

## Context to load

## Steps
For each finding, first write the test that fails without the fix. If a finding turns out to be wrong, keep the code, add the test that proves it, and say so in the report.

**Part A: card payments and refunds (E8-T04 round-3 review)**
1. A Stripe request that exhausts its retries without a returned intent is not a definitive failure: reconcile it with Stripe before marking the payment failed (#1, `CardPayments.java:124`).
2. An exhausted refund command never reserves money for good: release or retry it, and test an invalid provider configuration (#2, `PaymentRefunds.java:67`).
3. Refund allocation uses each row's stored Stripe capture, not its total `amountPaid` (#3, `PaymentRefunds.java:236`).
4. An earlier partial refund does not suppress the cancellation compensation still due (#4, `PaymentRefunds.java:102`).
5. Run completion follows the unresolved Stripe collections, including a late success of an earlier attempt (#5, `CardPayments.java:169`).
6. A refund made directly in Stripe writes its `PAYMENT_REFUNDED` audit entry (#6, `PaymentRefunds.java:218`).

**Part B: leave, reactivation and cancellations (E8-T05 round-2 review)**
7. Reactivation never leaves dogs active without their individual approval, whatever the order of reactivation and the `MemberStatusChanged` dispatch (#1, `LeaveRequestService.java:135`).
8. Cancellations select bookings by the class's real start time, not by asynchronously refreshed copies (#2, `CensusBookingCancellations.java:22`).
9. Leave execution writes `leftAt` and `leftReason` inside the audited transition, so the «before» snapshot is the real one (#3, `LeaveScheduler.java:27`).
10. N-18b's templates (ca, es, en) include the inactivity fee and read well for an open-ended period (#4, `message-templates.*.json`).
11. The test-class inventory in E8-T05's evidence includes `BillingPortDefaultsTest` (#5).
