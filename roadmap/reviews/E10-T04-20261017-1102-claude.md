## Findings
1. **nit** `docs/specs/S17-consola-de-clubs.md:84` — **The state diagram does not match the code for a primary `PENDING` domain.**
   - **What is wrong:** the diagram still shows `PENDING --> [*] : eliminat` with no condition. `PlatformDomains.remove` refuses any primary domain, including a `PENDING` one (only an old `club:apply` can leave one behind). The report states this as an assumption, and the code is the sensible choice.
   - **Fix:** add "(si no és el principal)" to the `PENDING` edge too, so S17 §5 matches the code and the contract description.
2. **nit** `docs/specs/00-transversal/CONVENCIONS_API.md:59` — **The new route is missing from the route list.**
   - **What is wrong:** the S17 route-family line lists `/platform/...` and `/internal/domains/allowed`, but not the new club-scoped `/support-accesses/{id}`. Every other S17 route is listed there.
   - **Fix:** add it when the organizer syncs the transversal docs.
3. **nit** `src/main/java/com/agilityhub/core/identity/application/SupportAccessService.java:49` — **The filter pattern misses `HEAD`, and no test covers it.**
   - **What is wrong:** `RESTRICTED` only names `GET|POST` for exports. Spring MVC also sends `HEAD` to `GET` handlers, so `HEAD /api/v1/members/export` gets past the filter.
   - **Why it is only a nit:** the `@SupportRestricted` interceptor still refuses it before the handler runs, so nothing leaks and no export side effect happens. But no test covers this, and the consistency test `T_17_09_R_17_10_everyRestrictedRouteRefusesASupportTokenInItsHandler` only enumerates declared methods.
   - **Fix:** add `HEAD` to the pattern, or add one `HEAD` case to `SupportAccessIT`.
4. **nit** `src/main/java/com/agilityhub/core/shared/api/IdempotencyFilter.java:202` — **The new club-existence check can fail when another club is already the active tenant.**
   - **What is wrong:** the check calls `ClubLocaleSettingsProvider.settings(clubId)`, which opens `TenantContext.open(clubId)`. If a different tenant is already open on the request (a console call sent with a club's `Host`), that open throws `TENANT_MISMATCH` instead of letting the request through unkeyed.
   - **Why it is only a nit:** round 1's `Rows` already has the same constraint, and the console normally runs on the product host, where no tenant is open. It is worth a code comment or a test with a club `Host`.
5. **nit** (style, many controllers) — **Fully qualified annotation instead of an import.** `@com.agilityhub.core.shared.application.SupportRestricted` is written out in full on 22 handlers. This matches the fully qualified style already common in those files, so it is acceptable; an import would read better.
