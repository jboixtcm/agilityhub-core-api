3. **nit** `src/main/java/com/agilityhub/core/platform/application/ClubSettingsService.java:71-74` and `ClubDefinitionWriter.java:~109`: the tax id is checked on the raw string and stored as typed.
   - **What happens.** `ES` accepts `"g-6318 9617"` (CountryProfileTest). That value is then published verbatim as `/branding.taxId` in the LSSI footer.
   - **Knock-on effect.** The equality test is also on raw strings. So resending a stored value with different spacing re-runs the check.
   - **Fix:** store the normalized form (upper case, no separators), and compare normalized values. Or leave it and note it for S02.
