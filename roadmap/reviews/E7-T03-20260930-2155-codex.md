# Review E7-T03 — needs changes

## Findings

1. **major** `src/main/java/com/agilityhub/core/clubs/messaging/application/engine/TemplateProvider.java:48` — Existing N-02 templates retain the broken welcome text. A template persisted by `ca83d97` still contains `Entra-hi amb aquest enllaç: [[link]].`; both this lookup and `club:apply` preserve it. New notifications therefore still render an empty link, and saving the unchanged body now fails with `TEMPLATE_UNKNOWN_VARIABLE` because round 2 removes `link` from allowed variables. This leaves E76 / round-2 item 6 unresolved for existing clubs. Add a conditional legacy correction that preserves unrelated club edits, and test GET → PUT and delivery using the actual previous template. The current regression test covers fresh seeds only.

2. **major** `src/main/java/com/agilityhub/core/clubs/messaging/domain/NotificationCatalog.java:75` — The advertised variable list still includes a value that delivery cannot populate: N-03 accepts `[[member_last_names]]` because it declares `member_name`. Preview supplies fictional surnames, but `CensusNotificationFacts.signup()` supplies no `member_last_names`, and `NotificationEngine.derived()` derives it only for `MEMBER`, not N-03’s `APPLICANT` audience. Consequently, an accepted template such as `Cognoms: [[member_last_names]].` previews correctly but sends `Cognoms: .`. This violates R-11-12 and round-2 item 2. Populate the applicant’s surnames and add a real `SignupRejected` rendering test; the new variable-parity test covers only N-09 and N-02.

3. **minor** `src/main/java/com/agilityhub/core/clubs/messaging/application/NotificationPreferencesService.java:108` — The preferences response substitutes `club.defaultLocale` when the account’s language is outside `club.locales`. For example, `Account.locale=en` in a `ca/es` club is reported as `ca`, contrary to Step 6’s explicit `locale = Account.locale` contract. This affects both profile and D10 responses. Return the stored account locale, keep `availableLocales` separate, and test this combination.
