2. **minor** `src/main/java/com/agilityhub/core/clubs/common/application/SavedViewData.java:8` + `SavedViewService.java:26` — The `system` flag is derived from the bare literal `"SYSTEM"`, which is duplicated in two classes. In practice account ids are generated, so this is not exploitable today. · **Suggested fix:** use a single constant, for example `SavedViewData.SYSTEM_OWNER`, in both places.
3. **minor** `src/main/java/com/agilityhub/core/clubs/census/application/CensusMigrationService.java:37,44` — This class writes `LeaveRequest` through `leaves.save`/`leaves.insert` directly. The impact is small: migrated requests are `MIGRATED`/non-`PENDING`, and the cache TTL is 30 s, which is within T-14-29's "< 60 s". · **Suggested fix:** narrow the claim in the report, or route the migration writes through the same hook.
