## Findings
1. **nit** `src/main/java/com/agilityhub/core/clubs/messaging/application/engine/NotificationEngine.java:139-140`: when a batch has no frozen copy, the engine skips it silently (`if (template == null) { continue; }`).
   - **Effect:** the outbox event is consumed with 0 notices while `announcements.recipientCount = N`, and nothing records it.
   - **Context:** report assumption R2-2 accepts this, and it can only happen on a database from before round 2. Still, a dropped announcement should be visible.
   - **Fix:** log a WARN with `batchId`/`templateId` (or count it in a metric) before the `continue`.
2. **nit** `src/main/java/com/agilityhub/core/clubs/messaging/application/engine/TemplateProvider.java:34-36`: production code keeps a 4-argument constructor that sets `announcements = null`.
   - **Effect:** with that constructor, `asSent` returns empty for every batch, so a future wiring that used it would drop every announcement without an error.
   - **Who uses it:** only tests (`TemplateProviderTest:30`, `MessagingE7T06UnitTest:197,266,283`).
   - **Fix:** remove it and pass `null` or a mock explicitly in those tests, or have `asSent` fail loudly when no repository is wired.
3. **nit** `src/main/java/com/agilityhub/core/clubs/messaging/domain/ChannelResolver.java:111-112`: the literal `"N-24"` is now duplicated in three places.
   - **Where:** `ChannelResolver.ANNOUNCEMENT`, `AnnouncementService.N24` and `ChannelTruthTable:145`.
   - **Rules:** this is a catalog code, not a club literal, so no AGENTS rule is broken.
   - **Fix:** keep one constant (for example next to `NotificationCatalog`) so the ruling-E82 rule and its test oracle cannot drift apart.
4. **nit** `src/test/java/com/agilityhub/core/clubs/messaging/application/engine/NotificationMatrixTest.java`: the matrix's own N-24 rows (no CUSTOM template) leave `facts.templateId` null, so they go through `forCode`.
   - **Gap:** in production every N-24 carries its batch's `templateId` and goes through `asSent`, even with N-24's own template.
   - **Coverage today:** only `AnnouncementsIT` batch C exercises the frozen copy of the catalog N-24 template. Rendering is equivalent today, so this is informational.
   - **Fix (optional):** have the matrix's N-24 owner always set a template id, as `MessagingNotificationFacts` does.
