# Review E11-T15 — needs changes

## Findings

1. **major** `src/main/java/com/agilityhub/core/migration/application/PlayoffPlanner.java:200` — “Paid until” overrides are silently ignored for same-NIF aliases merged without `persones.csv`. Only explicit `joins` are resolved, while `linkPlan` reads the principal row’s ID. An override on the secondary record therefore leaves the default date and can bill months already paid. This partially implements step 3 / R-18-13; report assumption 5 acknowledges the omission. Resolve overrides through the complete member-destination mapping and add a regression using the existing same-NIF records 1 and 184.

2. **major** `src/main/java/com/agilityhub/core/migration/application/PlayoffInput.java:34` — F6 still allows one malformed receipt or pack row to reject the entire migration. With a valid header but one data row missing a trailing column, this code emits `ERROR INPUT_SCHEMA_MISMATCH` before `PlayoffBillingPlanner` can downgrade it; `PlayoffImportService` then applies nothing. Step 6 / R-18-11b require per-row failures to be warnings and skipped records. Handle these row-width failures accordingly for receipts/packs, retain errors for invalid headers, and test that the census still imports.

3. **major** `src/main/java/com/agilityhub/core/migration/application/PlayoffPlanner.java:297` — Resolving a number conflict on re-import can produce an unusable mandate. The first import now stores null `mandateRef` and `mandateSignedAt`. After assigning a valid number, the reference is generated, but `getOrDefault("mandateSignedAt", …)` retains the existing null value. The warning disappears, yet `SepaRemittanceWriter` rejects the entire run for the missing signature. Use a null-aware fallback when generating the mandate and test conflict → corrected number → re-import, per step 7 / R-18-08.

4. **minor** `src/main/java/com/agilityhub/core/shared/domain/SepaCreditorIdentifier.java:25` — Checking only remainder 1 accepts noncanonical check digits. A JShell evaluation of this helper returned `true` for both `ES97ZZZB12345678` and `ES00ZZZB12345678`; step 8’s prescribed calculation yields `97`. Thus an invalid identifier can still pass both console and runtime validation. Compare against the calculated `98 − remainder`, or additionally reject digits outside `02…98`; add regression cases for the modulo-equivalent invalid digits.

5. **minor** `roadmap/tasks/E11-T15.md:223` — Verification evidence is incomplete under AGENTS.md’s evidence rule. The green unit command abbreviates its test selection with `…`, and several required final output tails are summarized instead of reproduced. Also, `13-reproductions.log` explicitly confirms that F5’s red test stopped at a missing response field before attempting rollback, so the requested red proof of the unsafe rollback is absent. Supply the exact commands and literal final tails, and capture a separate rollback regression failing on the old behavior.
