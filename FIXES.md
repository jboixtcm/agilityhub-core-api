## api-00-restore-class

### SCH-01 — FIXED
- Route `POST /api/v1/class-sessions/{id}/restoration` (ADMIN only, same guards as `…/cancellation`: `@PreAuthorize`, tenant and class checks, impersonation → 403 `IMPERSONATION_DENIED`), body `{}`, no `Idempotency-Key` (idempotent by state). 200 → the `ClassSession` schema the cancellation route returns, with `state: ACTIVE`, `cancellation: null`, `counters {booked: 0, waiting: 0}`. Errors: 404 `NOT_FOUND`; 409 `INVALID_STATE` (not CANCELLED, reason DELETED or missing, `startsAt ≤ now`, or a repeat); 409 `CLASS_CONFLICT` (another DRAFT/ACTIVE class of the ring overlaps); 422 `RING_BLOCKED` (ACTIVE ring block); 422 `RING_HAS_BOOKINGS {bookings[]}` (live training booking, never cancelled). A class without a ring skips the ring checks.
- Code: `ClassSessionRules.restorable` (domain; `transition()` unchanged, so CANCELLED stays terminal in the lifecycle), `ClassSessionService.restore` (creation's ring checks moved into `ringFree`, now shared by create/move/restore), `SchedulingAudit.restored` with the new `AuditAction.CLASS_RESTORED` (+ `AuditContracts.AuditActionName`, S14 R-14-09 row, snapshot enum). No booking, waiting-list entry or hold is re-created and nothing is notified; it publishes `ClassSessionUpdated{diff: {state}, bookedCount: 0}` (no N-08b; S09 drops that day's grid cache). Docs: S06 §5/§6/Canvis, `MATRIU_PERMISOS`, `CATALEG_ERRORS` S06 row (+`CLASS_CONFLICT`, reused from S09). `docs/openapi/openapi.json` was edited with a script that reproduces the Jackson snapshot format byte for byte, not regenerated (`bin/openapi-snapshot` needs Docker): regenerate it in CI.
- Tests: `CalendarRulesTest.SCH_01_onlyAFutureCancelledClassThatWasNotDeletedIsRestorable` ran and passed (with a reflection runner, because the Surefire plugin is not in the offline `~/.m2`), as did `AuditContractTest`, `E5RouteParityTest`, `ErrorCatalogContractTest`, the snapshot contract unit tests and the production ArchUnit rules. Not run (MongoDB): `CalendarIT.SCH_01_anAdminRestoresAFutureCancelledClassWithoutItsBookingsNoticesOrAnOccupiedRing` (`@AuditCovers(CLASS_RESTORED)`) and the new route in `e4-routes.json` / `E4ContractIT` (target `cancelled-a`, 57 routes).
